# kledgame
A game where you play as Kled! 
Controls: WASD to move, S to duck arrows while dismounted and hit enemies, Q to shoot while dismounted, E to dash while mounted, spacebar to attack, kill 20 enemies to remount. Attack the flags for a boss fight!
Made with SDL2, requires SDL2, SDL_TTF, SDL_Image, SDL_mixer to compile successfully
Note: the .exe needs to have the resources folder in the same directory and the font.ttf file
Made in 2017 for a school project!
